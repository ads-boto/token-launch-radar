How the radar values a launch

One model, every row

The implied value is a sector multiple of TVL, moved by the protocol's seven-day growth, how long it has run without a recorded token, and how many chains it reaches. No protocol is named in the arithmetic; the same four functions score a $20M launch candidate and a $2.7B one.

Sector multiples

        
FDV / TVL benchmarks by DefiLlama sector, the only name-dependent input, and it is a sector, never a protocol.

        

      

      

        
What this is not

        
It is not a forecast that a token launches, nor a price target: the snapshot records no supply, so the value is an FDV estimate in dollars. A protocol may run for years and never issue a token. The farm plans describe activity that may earn a future allocation; they are not investment advice and the capital can be lost.
